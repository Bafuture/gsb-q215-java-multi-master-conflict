|------|------|

```bash
./mvnw -q verify
```

## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们多个主节点都能写入，同步时会出现同一键被两边同时改的情况，需要按规则解决冲突。请从零实现一个多主复制的冲突检测与解决组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 每次写入带逻辑时钟与节点标识，形成版本元数据；2) 支持版本比较：能判断两个写入是先后关系还是并发冲突；3) 冲突解决策略至少实现两种：按时间戳取新（需说明时钟不可靠的风险）与按节点优先级取高，策略可配置；4) 支持无冲突合并：同一键不同字段被分别修改时要能合并而不是整体覆盖；5) 支持收敛性验证：任意顺序同步后所有节点最终状态一致（需有测试证明）；6) 支持冲突记录：保留被覆盖的值与冲突原因，供人工排查；7) 提供统计：同步轮次、冲突次数、按策略解决次数与保留的冲突记录数；8) 测试覆盖版本比较、两类策略、字段级合并、收敛性、冲突记录与统计；`mvn -q verify` 一条命令跑通。

## 提交要求

1. 在本仓库中完成提示词要求的全部内容。
2. `./mvnw -q verify` 必须通过。
3. 完成后在所属分支（A 或 B）上提交，产物快照的父提交必须是初始环境快照。
